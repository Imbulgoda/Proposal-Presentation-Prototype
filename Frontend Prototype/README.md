# FedNutri-XAI

AI-Powered Childhood Nutrition Intelligence System — final-year research prototype.

## Stack

- React + Vite
- Tailwind CSS
- React Router
- Recharts
- React Leaflet
- jsPDF / XLSX / PapaParse
- React Hot Toast
- Lucide React

## Run

```bash
npm install
npm run dev
```

Demo login accepts any username/password. Default role: MOH Officer.

## Notes

All data is simulated for research demonstration. No live database or AI API is connected.
